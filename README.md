# Car-Picker
Car Picker is a smart app to help users rent or buy cars easily. It offers categorized listings, car specs, images, reviews, bookings, secure login, and flexible payments. Built with ASP.NET Core and SQL Server, it’s a full-stack project showcasing real-world system design and user-focused features.

# 🚗 Car Picker API

**Car Picker API** is a robust and extensible RESTful web service built with **ASP.NET Core (.NET 8, C# 12)**. It provides a complete backend solution for car rental or comparison platforms, supporting vehicle listings, bookings, payments, authentication, category filtering, and reviews.

---

## 📌 Features

- 🔐 **Authentication & Authorization** – Secure user login, registration, and role-based access.
- 🚗 **Car Management** – Create, read, update, and delete cars.
- 📅 **Booking System** – Book vehicles and manage reservation details.
- 💳 **Payment Handling** – Process booking payments securely.
- 🏢 **Office Management** – Manage rental branches or offices.
- 🗂️ **Category Filtering** – Organize and filter cars by categories.
- 🌟 **Reviews** – Add and read reviews for cars and rental offices.
- 🖼️ **Image Uploads** – Upload and serve images via the `/uploads` endpoint.
- 📘 **Swagger Integration** – API documentation and testing via Swagger UI.
- 🔄 **CORS Support** – Configurable for cross-origin requests.
